# Multilingual Speech Intelligence

An AI system for multilingual speech understanding using speech recognition, audio representations, RAG, and agentic workflows.

## Initial Goal

The system will process audio in languages such as Darija, French, and English.

Initial pipeline:

Audio → Whisper → Transcript → LLM → Answer

Later versions will include:

- WavLM
- RAG
- Vector database
- LangGraph agents
- Research document retrieval
- FastAPI
- Streamlit
- Docker
